> STEGANOGRAPHY

Hide a text message inside an image's pixel data (LSB encoding - one bit per color channel, invisible to the eye). Output is always PNG: JPEG's lossy recompression destroys the hidden bits, so re-saving or re-uploading a stego image anywhere that re-encodes it as JPEG will wipe the message. Nothing is uploaded anywhere - the image never leaves your browser.

> HIDING THAT SOMETHING'S HIDDEN

                
Cryptography hides what a message says. Steganography hides that a message exists at all - an encrypted file announces "there's a secret here," a steganographic one doesn't. This tool's LSB (least-significant-bit) encoding swaps the lowest, least visually significant bit of each color channel for a bit of the hidden message, nudging every affected pixel's color by an amount too small to see - which is also why it only ever outputs PNG: anything that recompresses the image scrambles those low bits and destroys the message.
