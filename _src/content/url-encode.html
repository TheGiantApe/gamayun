> URL_CODEC

Direction is auto-detected - paste a percent-encoded string to decode it, or plain text to encode it, no mode switch to remember. Detection works because a real percent-encoded byte (%2F, %3D, and so on) is a hex pair plain text essentially never contains by coincidence. Decoding also handles the older application/x-www-form-urlencoded convention where a literal + means a space, which a bare decodeURIComponent() call leaves untranslated.
