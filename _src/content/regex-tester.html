> REGEX_TESTER

Live matching against your browser's own native regex engine - the exact engine your actual code runs against, not a reimplementation that could disagree with it on an edge case. Uses matchAll() rather than the classic manual exec()-in-a-while-loop, which sidesteps that pattern's well-known infinite-loop bug on a zero-length match for free. All matches highlighted, with capture groups and named groups broken out below.
