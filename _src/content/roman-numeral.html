> THE SUBTRACTIVE RULE

Roman numerals mostly add left to right (VI = 5+1 = 6), but a smaller numeral placed immediately before a larger one subtracts instead (IV = 5-1 = 4). Only specific pairs are valid this way - I before V or X, X before L or C, C before D or M - and a numeral can only be repeated up to three times in a row (IIII is not valid, IV is). This tool checks both rules, so a malformed string like "IIII" or "VX" gets a specific explanation instead of a silent wrong answer.
