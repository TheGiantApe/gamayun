> TEXT_DIFF

Paste an original and a changed version, get a real line-by-line diff (a classic longest-common-subsequence comparison, the same category of algorithm behind diff/git's own line diffing) rather than a rough "these look different somewhere" guess. Built for the size of text people actually paste - a paragraph, a config file, a changelog - not whole-file diffing of huge documents, where the same algorithm gets noticeably slower.
